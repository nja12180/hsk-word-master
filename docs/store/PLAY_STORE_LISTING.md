## 5. 개인정보처리방침 호스팅 (GitHub Pages)

Play Console은 개인정보처리방침의 **공개 접근 가능한 URL**을 요구합니다.
GitHub Pages로 무료·영구 호스팅하는 것을 권장합니다.

### 5.1 배포 절차

```bash
cd /home/user/flutter_app

# gh-pages 브랜치용 임시 디렉터리 구성
mkdir -p /tmp/ghpages
cp docs/store/privacy-policy.html /tmp/ghpages/index.html
cp docs/store/privacy-policy.html /tmp/ghpages/privacy-policy.html

# 기존 gh-pages 브랜치로 강제 푸시 (orphan 브랜치)
cd /tmp/ghpages
git init -q
git checkout -q -b gh-pages
git add -A
git -c user.name="HSK Word Master" -c user.email="nja12180@users.noreply.github.com" \
    commit -qm "docs: 개인정보처리방침 배포"
git remote add origin https://github.com/nja12180/hsk-word-master.git
git push -f origin gh-pages
```

### 5.2 GitHub Pages 활성화

1. GitHub 저장소 → **Settings** → **Pages**
2. Source: **Deploy from a branch**
3. Branch: **gh-pages** / 폴더: **/(root)** → **Save**
4. 1~2분 후 아래 URL 활성화

```
https://nja12180.github.io/hsk-word-master/privacy-policy.html
```

### 5.3 확인

```bash
curl -s -o /dev/null -w "%{http_code}\n" \
```

## 6. (선택) Android 자동 백업 차단

데이터 보안 선언을 "전송·백업 없음"으로 더 명확히 하려면 `allowBackup`을 끌 수 있습니다.

`android/app/src/main/AndroidManifest.xml`:

```xml
<application
    android:label="HSK 단어마스터"
    android:name="${applicationName}"
    android:icon="@mipmap/ic_launcher"
    android:allowBackup="false"
    android:fullBackupContent="false"
    android:dataExtractionRules="@xml/data_extraction_rules">
```

`android/app/src/main/res/xml/data_extraction_rules.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<data-extraction-rules>
    <cloud-backup>
        <exclude domain="root" />
        <exclude domain="database" />
        <exclude domain="sharedpref" />
        <exclude domain="file" />
    </cloud-backup>
    <device-transfer>
        <exclude domain="root" />
        <exclude domain="database" />
        <exclude domain="sharedpref" />
        <exclude domain="file" />
    </device-transfer>
</data-extraction-rules>
```

> 이 설정을 적용하면 기기 변경 시 학습 기록이 이전되지 않습니다.
> 학습 기록 승계를 원한다면 기본값(백업 허용)을 유지하고, 스토어 설명에
> "학습 기록은 기기 내부에만 저장됩니다"라고 안내하는 현재 방식이 적절합니다.
