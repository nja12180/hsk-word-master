- 광고가 없어도(오프라인) 학습 기능은 전부 동작합니다.

## 6. (선택) Android 자동 백업 차단

데이터 보안 선언을 "전송·백업 없음"으로 더 명확히 하려면 `allowBackup`을 끌 수 있습니다.

`android/app/src/main/AndroidManifest.xml`:

```xml
<application
    android:label="HSK 단어마스터"
    android:name="${applicationName}"
    android:icon="@mipmap/ic_launcher"
    android:allowBackup="false"
    android:fullBackupContent="false"
    android:dataExtractionRules="@xml/data_extraction_rules">
```

`android/app/src/main/res/xml/data_extraction_rules.xml`:

```xml
<?xml version="1.0" encoding="utf-8"?>
<data-extraction-rules>
    <cloud-backup>
        <exclude domain="root" />
        <exclude domain="database" />
        <exclude domain="sharedpref" />
        <exclude domain="file" />
    </cloud-backup>
    <device-transfer>
        <exclude domain="root" />
        <exclude domain="database" />
        <exclude domain="sharedpref" />
        <exclude domain="file" />
    </device-transfer>
</data-extraction-rules>
```

> 이 설정을 적용하면 기기 변경 시 학습 기록이 이전되지 않습니다.
> 학습 기록 승계를 원한다면 기본값(백업 허용)을 유지하고, 스토어 설명에
> "학습 기록은 기기 내부에만 저장됩니다"라고 안내하는 현재 방식이 적절합니다.

## 9. 광고 도입 로드맵 (하단 배너)

### 9.1 왜 지금은 넣지 않는가

| 이유 | 설명 |
|---|---|
| 심사 변수 최소화 | 광고는 데이터 보안·등급 설문 재응답을 유발해 심사 지연 위험 |
| 반응 기반 설계 | 실제 사용자가 어느 화면에 머무는지 확인 후 광고 위치 확정 |
| 첫인상 보호 | "4,184개 무료, 광고 없음" 이 초기 다운로드 전환에 유리 |
| 기술 리스크 | AdMob SDK 추가 시 minSdk·권한·ProGuard 이슈 검증 필요 |

### 9.2 배너 배치 원칙

| 화면 | 배너 | 비고 |
|---|---|---|
| 홈 (HomeScreen) | ✅ 하단 고정 | 학습 시작 전 노출, 이탈률 낮음 |
| 단어장 (WordListScreen) | ✅ 하단 고정 | 스크롤 목록 하단은 자연스러움 |
| 통계 (StatsScreen) | ✅ 하단 고정 | 체류 시간 짧아 부담 적음 |
| **학습 (StudyScreen)** | ⚠️ **신중** | 카드 플립 집중도 방해 가능. A/B 테스트 권장 |
| **퀴즈 (QuizScreen)** | ❌ **금지** | 정답 입력 중 오터치 유발, 정책 위반 소지 |

> **절대 금지**: 학습 카드 위에 오버레이되거나, 카드 플립 애니메이션 중
> 리레이아웃을 유발하는 배치. `Scaffold.bottomNavigationBar` 대신
> 본문 Column 하단에 고정 배치하고, SafeArea를 반드시 적용합니다.

### 9.3 수익 예측 (보수적)

| 항목 | 가정 |
|---|---|
| DAU | 100명 (출시 3개월) |
| 1인당 일 노출 | 12회 (배너 기준) |
| 일 총 노출 | 1,200회 |
| eCPM (한국, 교육 카테고리) | 1,000~2,500원 |
| **일 수익** | **1,200 ~ 3,000원** |
| **월 수익** | **3.6만 ~ 9만원** |

> 배너 단독으로는 수익이 크지 않습니다. 광고는 **서버·도메인 등 운영비
> 충당 수준**으로 기대하시고, 수익 확대는 추후 "광고 제거 프리미엄(IAP)"
> 검토를 권장합니다.

### 9.4 광고 도입 시 지켜야 할 Google 정책

| 정책 | 요구사항 |
|---|---|
| 광고 ID | `AD_ID` 권한 선언 + 개인정보처리방침에 명시 (완료) |
| 맞춤 광고 동의 | EEA·영국·스위스 사용자에게 UMP 동의 팝업 필수 |
| 아동 대상 | 만 13세 미만 대상 아님 → 가족 정책 미적용 (현재 설정 유지) |
| 광고 배치 | 콘텐츠와 광고의 시각적 구분, 오터치 유도 금지 |
| app-ads.txt | 게시 필수 (수익 보호 및 스푸핑 방지) |
| 자기 클릭 금지 | 개발자 본인 기기에서는 테스트 광고 ID만 사용 |
